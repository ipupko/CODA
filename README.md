# CODA
CODA: Comprehensive Omics Downstream Analysis

CODA is a post-analysis results processing toolkit for large-scale genetic and omics studies. It picks up after the analysis is done, taking raw results from GWAS, Mendelian randomisation, polygenic risk scoring, fine-mapping, colocalization and similar pipelines and putting them through a structured layer of quality checking and visualisation.
The goal is simple: before you trust a result, check it. Before you publish a figure, make it worth publishing.
Built on the same philosophy as CRISP: plain instruction files, no GUI required, runs comfortably on a laptop or a 1000-core HPC cluster. Each module is self-contained, auditable, and produces structured QC reports alongside publication-ready figures.
CODA is part of the Compass Genomics Suite tools developed by Igor Pupko:

CRISP - genotype quality control

CAIRN - phenotype and metabolomics imputation

CRISP-py - Python-native reimplementation of CRISP

CODA - post-analysis QC and result visualisation

Status: Reserved. Active development begins after CRISP-py v1.0.
